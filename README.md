# SplitMate

Split expenses. Settle smarter.

SplitMate is a full-stack personal finance and expense-sharing platform
inspired by applications such as Splitwise.

## Tech Stack

### Backend
- Java
- Spring Boot
- PostgreSQL

### Frontend
- React
- Vite
- JavaScript

### Mobile
- React Native
- Expo

### Cloud
- AWS

## Project Status

🚧 Under Development

## Architecture

SplitMate will initially follow a modular monolith architecture.

React → Spring Boot → PostgreSQL

Additional services and infrastructure will be introduced incrementally
when required by the application's scale or functionality.
